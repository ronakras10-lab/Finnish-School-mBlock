# Finnish School – Learning mBlock

## What Is mBlock.cc?

**mBlock** is a programming platform that helps students learn coding and robotics. It allows us to create programs using visual blocks or Python.

It is useful for beginners because it makes programming easier to understand.

## How Do We Connect mBot2 to mBlock?

To connect mBot2 to mBlock, we follow these steps:

1. Open the [mBlock website](https://mblock.cc/).
2. Connect mBot2 to the computer using a USB cable.
3. Open the Devices section.
4. Select mBot2.
5. Click Connect and choose the available connection method.
6. Wait until the robot is connected.

## Block Programming vs Python Programming

There are two ways to program using mBlock.

**Block Programming:**
- Uses visual programming blocks.
- We drag and connect blocks together.
- It is easier for beginners.
- We do not need to write commands manually.

**Python Programming:**
- Uses written programming commands.
- We write instructions using Python.
- It helps us understand coding in more detail.
- It gives us more control over our programs.

## How Do We Run a Program Using mBlock?

To run a program, we follow these steps:

1. Open mBlock.
2. Select the mBot2 device.
3. Create a program using blocks or Python.
4. Connect the robot to the computer.
5. Click Run or Upload, depending on the programming mode.
6. Observe how the robot performs the instructions.

## Why Is mBlock Useful for Learning Robotics?

mBlock is useful because it makes programming more interactive and easier to understand.

It helps us:
- Understand programming logic.
- Learn how robots work.
- Create different programming activities.
- Develop problem-solving skills.

We use *visual programming* to understand how instructions work together.
